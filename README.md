# Motor-Link ⚡📱

Sistema didático de controle e supervisão de acionamentos elétricos de potência via interface web mobile para laboratórios do SENAI.

Permite que os alunos acionem e monitorem o status de contatores e motores trifásicos (220V) a partir de seus próprios smartphones, através de um circuito de comando isolado em 24V chaveado por Arduino via porta Serial COM ligada ao computador/notebook da bancada.
